🧪 Test Scenarios

Scenario 1: Normal Operation (Backend Online)

Test Steps:
  1. Open application with backend running
  2. Add fuel logs, soil logs, stations, and staff
  3. Verify data appears in UI immediately
  4. Check browser localStorage for backup data
  5. Verify API calls succeed

✅ EXPECTED RESULT: Data saved to both Supabase and localStorage, UI shows "ONLINE" status

Scenario 2: Backend Offline During Data Entry

Test Steps:
  1. Start with backend online, then stop backend server
  2. Add new fuel/soil logs
  3. Verify UI shows "OFFLINE" status
  4. Check offline queue counter in header
  5. Restart backend and verify queue processes

✅ EXPECTED RESULT: Data saved locally, queued for sync, auto-synced when backend returns

Scenario 3: Complete System Restart

Test Steps:
  1. Add data with backend online
  2. Add data with backend offline
  3. Close browser completely
  4. Restart browser and navigate to application
  5. Verify all data is present

✅ EXPECTED RESULT: All data recovered from localStorage, no data loss

Scenario 4: Export/Import Data Backup

Test Steps:
  1. Create diverse dataset (fuel logs, soil logs, stations, staff)
  2. Export data using header menu
  3. Clear all localStorage data
  4. Import the exported data
  5. Verify all data restored correctly

✅ EXPECTED RESULT: Complete data backup/restore cycle works perfectly

🚀 Manual Testing Instructions

Quick Test (5 minutes)

  1. Open Application: Navigate to http://localhost:5174
  2. Check Status: Look for green "ONLINE" indicator in header
  3. Add Data: Create 1-2 fuel logs and 1 soil log
  4. Refresh Page: Verify data persists after page reload
  5. Test Export: Click database icon → Export Data

Comprehensive Test (15 minutes)

  1. Backend Online Test:
    • Add fuel station, staff member, fuel log
    • Verify immediate UI updates
    • Check localStorage has backup
  2. Offline Mode Test:
    • Stop backend server (Ctrl+C in terminal)
    • Add more data - should see "OFFLINE" status
    • Check queue counter increases
    • Restart backend - queue should process automatically
  3. Recovery Test:
    • Close browser completely
    • Reopen application
    • Verify all data present
  4. Backup Test:
    • Export all data
    • Clear localStorage (Dev Tools → Application → Storage → Clear)
    • Import data back
    • Verify complete restore
